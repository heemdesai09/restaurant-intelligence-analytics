About This Project

This application demonstrates big data processing, indexing, and multi-stage aggregation pipelines on MongoDB's official sample_restaurants dataset using Scala 3.

Architecture: Scala 3 Backend (Repository Pattern + Service Layer) + Clean College Web UI
Database: MongoDB Atlas (sample_restaurants database, restaurants collection)
CRUD Operations: Add Restaurant, Multi-Filter Search, Update Record, Delete Record
Indexes Demonstrated: name, cuisine, and compound borough + cuisine

Restaurant Analytics & Aggregations

Computed using genuine MongoDB aggregation pipelines ($match, $group, $sort, $unwind, $limit).

Restaurants by Cuisine (Top 10)

Pipeline: [ { $match: { cuisine: { $ne: null } } }, { $group: { _id: "$cuisine", count: { $sum: 1 } } }, { $sort: { count: -1 } }, { $limit: 10 } ]

Restaurants by Borough

Pipeline: [ { $match: { borough: { $nin: [null, "", "Missing"] } } }, { $group: { _id: "$borough", count: { $sum: 1 } } }, { $sort: { count: -1 } } ]

BoroughRestaurant Count

Average Inspection Score by Cuisine

Pipeline: [ { $unwind: "$grades" }, { $match: { "grades.score": { $gte: 0 } } }, { $group: { _id: "$cuisine", avgScore: { $avg: "$grades.score" } } }, { $sort: { avgScore: -1 } } ]
